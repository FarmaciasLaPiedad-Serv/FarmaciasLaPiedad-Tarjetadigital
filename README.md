# Farmacias La Piedad - Tarjeta Digital

Tarjeta digital de contacto para Farmacias La Piedad, desarrollada con HTML, CSS y JavaScript y preparada para publicarse mediante GitHub Pages.

## Funciones

- Llamada directa.
- Contacto por WhatsApp.
- Acceso a la ubicación en Google Maps.
- Enlace a Facebook.
- Descarga de contacto en formato vCard.
- Diseño adaptable a teléfonos, tabletas y computadoras.

## Estructura

```text
TarjetaDigital/
├── index.html
├── css/
│   └── estilos.css
├── js/
│   └── app.js
├── img/
│   └── logo.png
├── contacto/
│   └── FarmaciasLaPiedad.vcf
├── docs/
├── README.md
└── .gitignore
```

## Uso local

Abre `index.html` en un navegador o utiliza la extensión Live Server de Visual Studio Code.
